# FlixCentralPlus

## 🚀 La mejor landing page de streaming

Landing page premium para FlixCentralPlus - Tu plataforma de entretenimiento definitiva.

### ✨ Características
- Diseño moderno y cinematográfico
- Totalmente responsive
- Animaciones fluidas
- Sección de precios con toggle mensual/anual
- FAQ interactiva
- Navbar glassmorphism
- Optimizada para conversión

Visita la demo: https://publicityvisual.github.io/flixcentralplus/

## Tecnologías
- HTML5
- CSS3 (Custom properties + Glassmorphism)
- Vanilla JavaScript
- Google Fonts (Outfit + Space Grotesk)

## Cómo usar
1. Clona el repositorio
2. Abre `index.html` en tu navegador
